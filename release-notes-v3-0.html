DataFlow v3.0 Release Notes

Released: October 1, 2024 | Version: 3.0.0

⚠️ BREAKING CHANGES: Pipeline syntax has changed. You must update your existing pipelines before October 15, 2024. See Migration Guide →
---

Major Changes

1. Pipeline Definition Syntax

We've simplified pipeline configuration to be more intuitive and reduce errors. The new YAML structure is cleaner and supports more complex scenarios.

Old Syntax (v2.x):

pipeline:
  name: "sync_customers"
  steps:
    - step_id: "extract"
      type: "source"
      source: "salesforce"
    - step_id: "transform"
      type: "transform"
      transformer: "custom_mapper"

New Syntax (v3.0):

pipeline:
  name: sync_customers
  steps:
    - name: extract
      type: source
      config:
        provider: salesforce
    - name: transform
      type: transform
      config:
        processor: custom_mapper

What Changed:

  • step_id → name
  • source, transformer` properties moved under config
  • All config values must use lowercase (no quotes needed for simple strings)
  • type value changed: "source" is now source

🔄 Automated Migration: Run dataflow migrate --from v2 --to v3 to auto-convert your pipelines. Manual review recommended.

2. Transformation Functions Library Expansion

New built-in functions reduce custom code needs by 50%. Write less, do more.

New Functions:

  • deduplicate(field, strategy) — Remove duplicate rows by field values
  • flatten_json(field) — Convert nested JSON to flat columns
  • date_diff(date1, date2, unit) — Calculate date differences
  • mask_pii(field, pattern) — Automatic PII masking (GDPR-compliant)
  • pivot(row_field, col_field, agg_func) — Dynamic pivot tables

3. Error Handling & Validation

Pipelines now validate on save, not on run. Catch errors 5 minutes instead of 30 minutes into execution.

  • Schema validation against source systems happens immediately
  • Missing dependencies (tables, APIs) detected during syntax check
  • Detailed error messages with suggested fixes
---

Performance Improvements

  • +40% faster: Parallel job execution across 8 cores (default). Configure with parallelism: 16 for GPU instances.
  • +25% memory efficient: Streaming transformations reduce peak memory by 25% for large datasets (>1GB).
  • -60% latency: Webhook events deliver in <2 seconds (was 5+ seconds in v2.5).

⚠️ What Breaks in v3.0

Action Required by October 15, 2024
Feature v2.x Behavior v3.0 Behavior
Pipeline YAML Validated at runtime Validated at save time
Error handling syntax on_error: "skip" error_policy: skip
Job timeout Default 8 hours Default 2 hours (set timeout: 480 for old behavior)
API v1 Fully supported Removed entirely
---

Deprecations

  • Custom source connectors: Support ends December 1, 2024. Use native adapters instead.
  • Dashboard v1: Old dashboard URL still works but shows deprecation banner. Migrate to Dashboard v2 by September 2025.
---

How to Upgrade

For Most Users (5-10 minutes):
1. Run auto-migration: dataflow migrate --from v2 --to v3
2. Test your pipelines in staging
3. Deploy to production
For Complex Pipelines: See DataFlow v2→v3 Migration Guide for step-by-step instructions, troubleshooting, and testing checklist.
