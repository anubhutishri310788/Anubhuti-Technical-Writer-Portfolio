DataFlow v2.5 Release Notes

Released: August 15, 2024 | Version: 2.5.0

📌 Highlights: Webhook event delivery, improved error handling, API v1 deprecation notice
---

What's New

✨ Webhook Event Delivery System

You can now receive real-time pipeline events directly to your infrastructure via webhooks. Subscribe to events like pipeline.completed, pipeline.failed, and job.error.

Use cases:

  • Trigger downstream processes when pipelines complete
  • Send alerts to Slack, PagerDuty, or custom monitoring systems
  • Log events to your data warehouse for compliance audits

View Webhooks API Reference →

🔒 Enhanced Error Handling & Retry Logic

Webhook events now include automatic retry with exponential backoff. Failed deliveries are logged and retried up to 5 times over 24 hours.

New fields in webhook payloads:

  • timestamp — ISO 8601 event timestamp
  • attempt — Delivery attempt number (1-5)
  • error_code — Specific error classification
  • context — Additional debugging information

📊 Improved Pipeline Monitoring Dashboard

New widgets show webhook delivery status, failure rates, and latency metrics in real time. Filter by event type or pipeline name.

---

Improvements & Bug Fixes

  • Fixed: Memory leak in long-running pipeline jobs (impacts pipelines with >100 steps)
  • Improved: Dashboard performance by 30% for large dataset views (>50,000 rows)
  • Fixed: Incorrect timestamp display in audit logs for UTC+5:30 timezones
  • Improved: Error messages now include actionable troubleshooting steps
---

⚠️ API v1 Deprecation Notice

Action Required by February 15, 2025

The DataFlow API v1 will be retired on February 15, 2025. All applications using the v1 endpoint must migrate to API v2 before this date.

Timeline

  • August 15, 2024 (Today): API v1 enters "sunset" phase. New features only in v2.
  • November 15, 2024: API v1 support reduced to critical security fixes only.
  • February 15, 2025: API v1 fully retired. All requests return 410 Gone.

What Changes?

v1 Endpoint (deprecated):

POST https://api.dataflow.io/v1/pipelines/run

v2 Endpoint (use this):

POST https://api.dataflow.io/v2/pipelines/{id}/executions

How to Migrate

Request body changes:

// v1 (old)
{
  "pipeline_id": "pipe_123",
  "params": {"key": "value"}
}

// v2 (new)
{
  "variables": {"key": "value"},
  "timeout_minutes": 60
}

Migration Guide: See DataFlow Migration Guide for step-by-step instructions.

---

Known Issues

  • Webhook Delivery Delay: Events may be delayed 2-5 minutes during peak usage hours (3-4 PM UTC). We're working on a fix for v2.6.
  • UI Glitch: Webhook retry logs may not display if browser cache is not cleared. Workaround: Hard refresh (Ctrl+Shift+R).
